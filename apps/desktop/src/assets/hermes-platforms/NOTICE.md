# Hermes channel marks

Retrieved 2026-09-26. These assets identify third-party services in the channel
picker, connection list and setup flow. They do not indicate service availability,
endorsement or affiliation. Brand names and trademarks belong to their owners.

Only the selected local files are bundled; rendering never contacts an icon CDN.
The complete icon libraries are not application dependencies. Email and IRC use
the application's Hugeicons Mail and Hash icons; unknown plugins use the generic
message icon.
